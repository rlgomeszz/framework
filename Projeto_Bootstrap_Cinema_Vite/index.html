CineBootstrap

Sistema web para cadastro e consulta de filmes, artistas, fichas técnicas e diretores.

A interface foi construída com Bootstrap 5, priorizando responsividade e componentes prontos.

Objetivo: demonstrar a aplicação prática de um framework CSS em um projeto com entidades e telas de CRUD.
