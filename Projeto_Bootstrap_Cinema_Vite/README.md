# CineBootstrap — Vite + Bootstrap

Projeto acadêmico para a atividade de Framework CSS.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Vite

## Entidades
Cada entidade possui:
- Cadastrar
- Detalhar
- Listar Todos

Entidades:
- Filme
- Artista
- Ficha Técnica
- Diretor

## Componentes Bootstrap
Navbar, Card, Accordion, Carousel, Tabs/Nav, Modal, Alert, Badge, Pagination, Offcanvas e Forms.

## Como executar

Abra o PowerShell dentro desta pasta:

```powershell
cd "C:\Users\Aluno\Downloads\Projeto_Bootstrap_Cinema_Vite"
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite, normalmente:
http://localhost:5173/

## Se o PowerShell bloquear npm.ps1

Use:

```powershell
npm.cmd install
npm.cmd run dev
```

## Importante
Agora o projeto possui package.json e Bootstrap é instalado pelo npm.
